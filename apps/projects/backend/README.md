# Projects backend

FastAPI-модуль Projects использует платформенный Access Service для входа и проверки JWT.
Старые `/api/auth/request-code` и `/api/auth/verify-code` здесь не обслуживаются.

Запуск, демонстрационные учётные записи и адреса gateway описаны в
[корневом README](../../../README.md#start-locally).
Настройки модуля перечислены в [.env.example](.env.example).
